TDA4j in your browser

A Scala 3 prompt with the library loaded. Nothing to install: it runs in this tab.

Starting…

To start with, one after the other (a click puts the line at the prompt):

Enter runs the input, or opens a new line while it is unfinished; an indented block ends with an empty line, as in the terminal. Shift+Enter always opens a new line, and Run runs what is there. The up and down arrows bring back earlier inputs.

Already imported: scala.language.experimental.modularity, cats.syntax.show.*, org.appliedtopology.tda4j.* and org.appliedtopology.tda4j.plot.*. A plot you view() appears below the line that made it.

This is the demo jar, java -jar tda4j-demo.jar, running in a Java runtime inside the page. It is several times slower than Java on your own machine, and an input with a type error can take ten seconds or more to answer. The first visit downloads about 50 MB. For bigger examples, or with no network, use the jar.
