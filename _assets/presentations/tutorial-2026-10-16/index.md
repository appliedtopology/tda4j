# What are we even doing?

TDA4j is a library for **persistent homology** and **cohomology**.
For a lightning fast summary:

* We can convert questions about shapes into questions about linear algebra.
* A triangulated mesh translates to a sequence of linear maps represented by matrices called the **boundary map**.
* Paths in the mesh translate to vectors in the "1-dimensional" component.
* Cycles are paths that start and end at the same vertex.

---

# What are we even doing?

TDA4j is a library for **persistent homology** and **cohomology**.
For a lightning fast summary:

* The boundary of a path is the formal difference of the endpoints.
* The boundary of a cycle is 0.
* The kernel of the boundary maps gets us generalized closed loops.
* The image of the boundary maps gets us loops generated by higher dimensional cells.
* The quotient vectorspace $H_d(X) = kernel / image$ captures significant generalized loops.

# What are we even doing?

TDA4j is a library for **persistent homology** and **cohomology**.
For a lightning fast summary:

* We can create these meshes (simplicial complexes) from data.
* By including a scale or focus parameter in the construction, we can encode geometry.
* Measuring stable features by how large their ranges of scale parameters are gives us topological descriptors.
* Hierarchical clustering == $H_0(data)$

# Open a Scala prompt and load in the library

The following command will open a REPL (read-evaluate-print loop) interpreter of Scala where we can write code and see results. This command has added flags to pull the TDA4j library from Maven in the snapshot version.

```shell
scala repl
```

And then load the library as a dependency:

```scala 3
:dep org.appliedtopology::tda4j:0.5.0
```

---

# Load the library 

(and also some required experimental Scala features)

```scala 3
import language.experimental.modularity // needed for some of the language features TDA4j uses
import org.appliedtopology.tda4j.*
```

And then let's create some points. For simplicity, let's just scatter a bunch of points on a circle.

```scala 3
val points = Array.tabulate(50)(i => Array(100*math.cos(i * math.Pi / 25), 100*math.sin(i * math.Pi / 25)))
```

---

# Compute persistent homology 

We start by accepting all default choices.

```scala 3
val diagram = Persistence(points)
val longbars = diagram.significant(25)
```

The resulting object can be queried for more details:

```scala 3
longbars.bars
longbars.triples
diagram.longest(2)
longbars.bars(1).representative
```

---

We could use the [Doodle](https://www.creativescala.org/doodle) library to visualize the results.
You can pull the library into the REPL environment with the `:dep` command:

```scala 3
:dep org.creativescala::doodle:0.34.0
```

Then we create a bunch of circles to mark the points.

```scala 3
val pointspic = points
  .map(row => Picture.circle(1).at(row(0),row(1)).fillColor(Color.black))
  .foldLeft(Picture.empty)((p,n) => p.on(n))
```

And we can write it out to file after creating a `frame` to hold size information:

```scala 3
val frame = Frame.default.withSize(225,225).withCenterAtOrigin
pointspic.write[Png]("foo.png", frame)
```

---

We can extend the `pointspic` picture to show the edges that form the one significant cycle.

```scala 3
val rep = longbars.bars(1).representative
val cycle = rep.rawEntries
  .map(_._1.toSeq)
  .foldLeft(OpenPath.empty)((p, st) => 
      p.moveTo(points(st(0))(0), points(st(0))(1))
       .lineTo(points(st(1))(0), points(st(1))(1)))
pointspic
  .on(Picture.path(cycle).strokeColor(Color.red))
  .write[Png]("foo.png", frame)
```
