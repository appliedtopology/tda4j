title: Topological spaces
---

TDA4j currently supports a far wider range of topological spaces than its predecessors, starting with Vietoris-Rips and witness complexes, but extending to alpha-, cubical , sparse approximate Vietoris-Rips, Čech and Dowker complexes, as well as support for finite simplicial sets. All of these are compatible with the generic homology engines, and several of them have dedicated optimized engines available.
