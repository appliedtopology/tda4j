# Security policy

Report a vulnerability through GitHub's private reporting: the **Security** tab of the
[repository](https://github.com/appliedtopology/tda4j), then **Report a vulnerability**. Please do not open a public
issue for it. Include the version, the input or call that triggers it, and what you observed.

Fixes go into the latest release; before 1.0 earlier versions are not patched.
