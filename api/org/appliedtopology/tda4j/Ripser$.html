def parseSparseDistanceMatrix(text: String, origin: String = ...): Array[Array[Double]]

--format sparse: one i j d triple per line (0-based vertex numbers and the distance, separated by commas or whitespace), a pair listed once. The number of points is the largest index plus one, as in ripser.cpp (a last vertex with no edge cannot be named). A pair that is not listed has no edge: its distance is +Infinity in the result, and a threshold below that leaves it out of the complex. Lines with i == j are skipped, as Ripser skips them; a pair listed twice is refused (Ripser would count it as two edges).

--format sparse: one i j d triple per line (0-based vertex numbers and the distance, separated by commas or whitespace), a pair listed once. The number of points is the largest index plus one, as in ripser.cpp (a last vertex with no edge cannot be named). A pair that is not listed has no edge: its distance is +Infinity in the result, and a threshold below that leaves it out of the complex. Lines with i == j are skipped, as Ripser skips them; a pair listed twice is refused (Ripser would count it as two edges).

Ripser's default threshold is infinite, so a complex built from this matrix needs the largest listed distance as its maxFiltrationValue (maxFiniteDistance) to be the flag complex of the listed edges.

def readBinaryLowerDistanceMatrix(path: String): Array[Array[Double]]
