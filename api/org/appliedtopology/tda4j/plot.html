final case class Axis(label: String = ..., min: Option[Double] = ..., max: Option[Double] = ..., ticks: Ticks = ..., extra: IndexedSeq[(Double, String)] = ..., grid: Boolean = ..., visible: Boolean = ..., transform: Transform = ..., format: Option[String] = ..., minusInfinity: Option[Boolean] = ..., side: Option[Side] = ..., reverse: Boolean = ..., padding: Option[Double] = ..., crossesAt: Option[Double] = ...)

One axis. min and max fix the ends of the visible range in data units (otherwise the marks' extent, padded); transform is the scale the data are drawn on; ticks chooses the tick positions and extra adds labelled ones (the ∞ mark); format is a printf pattern for the numbers; visible = false drops ticks, labels and baseline (a point cloud's frame). On a log axis what is at 0 (an H0 bar's birth) sits on a -∞ line below the lowest number, as an essential bar ends at ∞: minusInfinity = None draws the line when something is there, Some(true) always (panels that must line up), Some(false) never, leaving what is at 0 out and counting it. reverse runs the axis the other way (large values at the left, or at the bottom); padding is the fraction of the data's extent left empty at each end when the range is not fixed (default 0.04). side puts the axis on the other side of the plot (an x axis at the Top, a y axis at the Right). crossesAt draws the axis where the other axis has that value (an x axis through y = 0, a y axis through x = 0), in the data units of the other axis, with the numbers beside it and the label at the edge; a value the other axis does not show leaves the axis at the edge. Change an axis of a figure with Scale.x(...) and Labels(x = ...).

final case class ColorScale(ramp: Ramp = ..., lo: Double = ..., hi: Double = ..., label: String = ..., transform: Transform = ..., stops: Option[IndexedSeq[String]] = ..., guide: Boolean = ...)

How the data values of Paint.Value marks become colors: the figure's one continuous color scale, and the color bar drawn from it.

How the data values of Paint.Value marks become colors: the figure's one continuous color scale, and the color bar drawn from it.

Marks hold the values, not the colors, so the colors follow the figure's Palette and can be re-limited (Scale.color(min = 0, max = 10)) to put two figures on one scale. A Diverging scale is symmetric: lo = -hi. A Cyclic scale reads its values as turns, 0 and 1 being the same color.

Value parameters

guide

whether to draw the color bar

hi

the value of the high end

label

the color bar's title

lo

the value of the low end of the ramp

stops

the colors of a Sequential ramp, light to dark, instead of the palette's own (for example ColorScale.viridis); evenly spaced and mixed in OKLab

transform

how values are spread along a Sequential ramp (Transform.Sqrt for a heavy-tailed image); the other ramps are always linear. A Log10 scale that starts at 0 or below is a symmetric log, linear within a thousandth of its largest magnitude, so that every value has a color

The finer-grained look of a figure: what each piece of text, the gridlines, the axis lines, the tick marks, a frame and the plot area's own fill are like, where the plot's Style has only the font, the scales of text and marks, the legend's place and the background.

final case class Figure(marks: Vector[Mark] = ..., title: String = ..., subtitle: String = ..., x: Axis = ..., y: Axis = ..., legend: Vector[LegendItem] = ..., colorScale: Option[ColorScale] = ..., width: Int = ..., height: Int = ..., equalAspect: Boolean = ..., aspect: Option[Double] = ..., palette: Palette = ..., style: Style = ..., degrees: Map[Int, DegreeStyle] = ..., legendTitle: String = ..., elements: Elements = ..., legendPlace: LegendPosition = ..., caption: String = ..., tag: String = ..., description: String = ...) extends Plot

A 2-D figure: marks in data coordinates, two axes, a legend, an optional color scale. Immutable: + adds a mark or a Tweak (labels, scales, size, palette, style), ++ more marks, copy changes the rest. svg renders it (Svg); view() shows it live; save("f.svg") writes it.

A 2-D figure: marks in data coordinates, two axes, a legend, an optional color scale. Immutable: + adds a mark or a Tweak (labels, scales, size, palette, style), ++ more marks, copy changes the rest. svg renders it (Svg); view() shows it live; save("f.svg") writes it.

The parts follow the grammar of graphics: the marks are the data drawn, x and y the position scales, palette with degrees and colorScale the color scales, legend and the color bar their guides, style the look and elements its finer parts (each text, the lines, the plot area). legendPlace is where the plot puts its legend unless the style says otherwise. equalAspect keeps a unit of x as long as a unit of y when both axes are on one scale, and aspect is any other ratio of the length of a y unit to an x unit (Scale.aspect). caption is a line of text under the plot, tag the letter of a panel of a board, and description what a screen reader says of the plot (the `` of the SVG).

The renderer writes SVG for whatever font the reader's browser or tool picks and has no font metrics, so a width is the advance widths of the stock face of a generic family: Helvetica (the faces sans-serif, system-ui, Arial and Liberation Sans stand for), Times (serif) or a fixed width (monospace), letter by letter, so that a row of Ws is wider than a row of is. Exact for those faces and the faces with their metrics (Arial, Liberation Sans, Liberation Serif); a font with other proportions is further off (Inter, which system-ui is on some systems, is about 6% wider).

enum Transform

How data values become positions along an axis (or steps along a color ramp). The plots hold data in its own units; a transform is applied only when drawing, so the same figure can be shown on a linear or a log axis.

How data values become positions along an axis (or steps along a color ramp). The plots hold data in its own units; a transform is applied only when drawing, so the same figure can be shown on a linear or a log axis.

apply gives NaN for a value with no position of its own: zero or a negative number under Log10. The renderer does not leave such a value out: what is at 0 on a log axis sits on a -∞ line below the lowest number, and a log axis with a negative value is drawn as a symmetric log (Transform.SymLog), which it says under the plot. Only what is not a number at all is left out, and counted.

trait Tweak

A change to how a plot looks, kept as a value. Add it to a plot with +, combine tweaks with +, keep them in a val and use them on every figure of a paper:

A change to how a plot looks, kept as a value. Add it to a plot with +, combine tweaks with +, keep them in a val and use them on every figure of a paper:

val house = Style.slides + Palette.reference + Size(960, 540)
Plot.diagram(d) + house + Labels(title = "Noisy circle") + Scale.xy(Transform.Log10)

Tweaks change independent parts of a figure (its labels, its axes, its colors, its look), so tweaks of different parts can be added in any order; of the same part, the later one wins. A Palette, a Style, Labels, Size, the Scale constructors, Text, Lines and Guide are tweaks.

A tweak that has no meaning for a plot (an axis of a 3-D scene) refuses, saying so; one that merely has nothing to change (a color scale on a figure without one) leaves the plot as it is, so that one bundle fits every plot.

object Viewer extends MainRoutes

The live viewer: one browser tab that shows every plot view()ed from this JVM, newest first, as it arrives.

The live viewer: one browser tab that shows every plot view()ed from this JVM, newest first, as it arrives.

The first view() starts a small web server on 127.0.0.1 (port 8337, or a free one when that is taken; set another with the system property tda4j.plot.port or the environment variable TDA4J_PLOT_PORT) and opens the page in the default browser. Where there is no desktop to open it on (a remote machine, a container), it prints the address instead: open it yourself, forwarding the port if needed (ssh -L 8337:localhost:8337 host). Set TDA4J_PLOT_BROWSER=none (or the system property tda4j.plot.browser=none) to never open a browser. The page keeps a list of every plot shown, and reconnects by itself when the JVM restarts on the same port.

The server's threads are daemon threads: a REPL or script exits as usual, and the page then waits for a new one. Nothing here uses Swing or AWT windows, so it works the same from sbt console, scala and scala-cli on any OS.
