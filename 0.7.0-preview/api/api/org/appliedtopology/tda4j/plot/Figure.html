Figure

org.appliedtopology.tda4j.plot.Figure
final case class Figure(marks: Vector[Mark] = ..., title: String = ..., subtitle: String = ..., x: Axis = ..., y: Axis = ..., legend: Vector[LegendItem] = ..., colorScale: Option[ColorScale] = ..., width: Int = ..., height: Int = ..., equalAspect: Boolean = ..., aspect: Option[Double] = ..., palette: Palette = ..., style: Style = ..., degrees: Map[Int, DegreeStyle] = ..., legendTitle: String = ..., elements: Elements = ..., legendPlace: LegendPosition = ..., caption: String = ..., tag: String = ..., description: String = ...) extends Plot

A 2-D figure: marks in data coordinates, two axes, a legend, an optional color scale. Immutable: + adds a mark or a Tweak (labels, scales, size, palette, style), ++ more marks, copy changes the rest. svg renders it (Svg); view() shows it live; save("f.svg") writes it.

The parts follow the grammar of graphics: the marks are the data drawn, x and y the position scales, palette with degrees and colorScale the color scales, legend and the color bar their guides, style the look and elements its finer parts (each text, the lines, the plot area). legendPlace is where the plot puts its legend unless the style says otherwise. equalAspect keeps a unit of x as long as a unit of y when both axes are on one scale, and aspect is any other ratio of the length of a y unit to an x unit (Scale.aspect). caption is a line of text under the plot, tag the letter of a panel of a board, and description what a screen reader says of the plot (the `` of the SVG).
