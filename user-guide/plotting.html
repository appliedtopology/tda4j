tda4j/User Guide for TDA4j/Plotting

The plots draw what a persistence computation returns: barcodes, persistence diagrams, persistence images and landscapes, images, complexes at a scale, cycles, cocycles and circular coordinates, in 2-D and in 3-D. They are part of the library, in the package org.appliedtopology.tda4j.plot, and need no other dependency: plots are SVG, or a page with a small built-in 3-D viewer, and they show up in your browser while you work in a REPL. The API is young and may still change between releases.

The sections up to What there is are all that most readers need. Everything under Customizing a plot is reference: look up the element you want to change.

In a REPL: view()

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = Array.tabulate(40)(i => Array(math.cos(i * 0.157), math.sin(i * 0.157)))
val diagram = Persistence(points, maxDimension = 1)

Plot.barcode(diagram).view()
Plot.diagram(diagram).view()

The first view() starts a small web server on your machine (http://127.0.0.1:8337/) and opens it in your browser: one tab that lists every plot you have viewed, newest first, and shows each new one as it arrives. Nothing to install, no windows to manage, and the REPL exits as usual. On a remote machine or in a container the address is printed instead; forward the port (ssh -L 8337:localhost:8337 host) and open it locally. Set TDA4J_PLOT_BROWSER=none (or the system property tda4j.plot.browser=none) to never open a browser, and the system property tda4j.plot.port (or TDA4J_PLOT_PORT) for another port.

Into files: save

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = Array.tabulate(40)(i => Array(math.cos(i * 0.157), math.sin(i * 0.157)))
val diagram = Persistence(points, maxDimension = 1)

Plot.barcode(diagram).save("barcode.svg")            // plain light colors, no background
Plot.diagram(diagram).save("diagram.svg", Some(Theme.Dark))   // light ink, for a dark page
Plot.diagram(diagram).save("diagram.html")           // follows the reader's light or dark setting
Plot.side(Plot.barcode(diagram), Plot.diagram(diagram)).save("both.svg")

figure.svg() is the SVG as a string: a notebook cell that displays HTML, or any web page, shows it as it is.

A saved .svg has no background, so the figure takes the color of the paper, slide or page it goes onto; the cream behind a figure in the viewer, in figure.svg() and in an .html page is for a page of its own. A figure in the dark theme is light ink on nothing: put it on a dark page. Where a file must carry its own background (an image that has to be opaque, or a dark figure opened on its own), save figure.withOpaqueBackground(), or Palette.print + Style.print for a white one, as for a paper (see For a paper).

PNG and PDF

save writes SVG and HTML; a PNG or a PDF is one command on the saved .svg, with a tool that is already on most machines. The SVG is 96 pixels to the inch, so a scale of 2 is 192 dpi and 3.125 is 300 dpi.

# cairosvg (pip install cairosvg): PNG at 300 dpi, and a PDF that has the fonts it used inside
cairosvg diagram.svg -o diagram.png --scale 3.125
cairosvg diagram.svg -o diagram.pdf

# Chromium or Chrome: PNG at twice the size (the window is the figure's width and height), PDF on a page
chromium --headless --hide-scrollbars --force-device-scale-factor=2 --window-size=560,520 \
  --screenshot=diagram.png file:///path/to/diagram.svg
chromium --headless --no-pdf-header-footer --print-to-pdf=diagram.pdf file:///path/to/diagram.svg

# Inkscape 1.x: PNG, and a PDF with the text turned into outlines, for a publisher who wants no fonts
inkscape diagram.svg --export-type=png --export-dpi=300 --export-filename=diagram.png
inkscape diagram.svg --export-type=pdf --export-text-to-path --export-filename=diagram.pdf

# librsvg
rsvg-convert -f png -z 3.125 diagram.svg -o diagram.png
rsvg-convert -f pdf diagram.svg -o diagram.pdf

The figure names its fonts in a list, system-ui, ... by default and Helvetica, Arial, 'Liberation Sans', sans-serif in the print look (Style(font = ...) sets another), and a converter takes the first one it has installed: the letters of a PNG are those of that machine. For a figure that must look the same wherever it is opened, use a PDF, which holds the font, or Inkscape's outlines. Chromium's command line puts the figure in the corner of a letter-size page. A page that follows the reader's dark setting (.html) is not what a converter should be given: save the .svg in the theme you want (save("d.svg", Some(Theme.Dark))).

From MATLAB, Java and the command line

A result of the MATLAB interface draws itself: each plot... method returns a figure, to view() or save as above. Here, the loop of a noisy circle and its cycle, drawn over the complex at the scale where the loop is born:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)
import d.given
val loop = d.dim(1).longest.get

Plot.barcode(d).view()
Plot.cycle(points, loop.representative).over(Plot.complex(points, loop.birth)).save("loop.svg")

import org.appliedtopology.tda4j.matlab.*;

points = readmatrix('_docs/tutorials/data/noisy-circle.csv');
result = TDA4j.computeFromPoints(points, {'maxDimension', '1'});

result.plotBarcode().view();
loop = result.mostPersistentBar(1);          % the index of the loop's bar (counting from 0)
result.plotRepresentative(loop, result.birth(loop)).save('loop.svg');   % its 18 edges over the complex

result.save('circle.json');                  % everything, to plot again later
result = TDA4j.loadResult('circle.json');

import numpy as np
import tda4j

points = np.loadtxt("_docs/tutorials/data/noisy-circle.csv", delimiter=",")
result = tda4j.persistence(points, max_dimension=1)

result.plot_barcode().view()
loop = result.most_persistent_bar(1)       # the row of the loop's bar in result.bars (counting from 0)
result.plot_representative(loop, at=result.bars[loop, 1]).save("loop.svg")   # its 18 edges over the complex

result.save("circle.json")                 # everything, to plot again later
result = tda4j.load_result("circle.json")

In MATLAB, call the methods with dot syntax (fig.view(), fig.save('loop.svg')): save and view are also MATLAB functions. MATLAB itself is not run by the test suite; the same calls are made from Scala. In Python the methods are plot_barcode(), plot_diagram(), ... on the result, and the figure has svg(), html(), save(path) and view(); a notebook shows a figure by itself. The tweaks that take plain arguments are methods of a Python figure too, in snake_case (with_title("..."), with_x_scale("sqrt"), with_size(800, 600)), and tda4j.set_plot_defaults("palette=print") changes the look of all later plots, with the settings of the MATLAB setPlotDefaults.

method draws
plotBarcode(), plotBarcode(longest), plotDiagram() the reported bars; the subtitle says how many the threshold hid
plotRepresentative(i) bar i's cycle over the points, its cubical chain over a 2-D image, or its cocycle restricted to the complex at the bar's birth: the edges that close the loop
plotRepresentative(i, at) a cycle over the complex at scale at, or a cocycle restricted to the complex at at (Inf draws the whole cocycle)
plotInput(), plotComplex(at) the points or the image; the complex the result was computed from at at (a witness complex on its landmarks)
plotLandscape(dimension), plotPersistenceImage(dimension) the vectorizations, of every bar (as landscape and persistenceImage compute them)
plotInput3D(), plotComplex3D(at), plotRepresentative3D(i) the same in 3-D (cycles only)
mostPersistentBar(dimension) not a plot: the index of the most persistent reported bar of that dimension
circularCoordinates(...).plot(), toroidalCoordinates(...).plot() circular and toroidal coordinates

A result computed from a distance matrix or a relation has no coordinates: it draws its barcode, diagram, landscapes and persistence images, and says so for the rest. The command line draws the same figures with --plot:

java -jar tda4j-VERSION-assembly.jar --max-dimension 1 --save-result circle.json noisy-circle.csv
java -jar tda4j-assembly.jar --plot diagram --output diagram.svg circle.json
java -jar tda4j-assembly.jar --plot representative circle.json
java -jar tda4j-assembly.jar --plot barcode,diagram --layout 1x2 --tagged circle.json

The first line computes and prints the bars, and saves the whole result; the others plot it without computing again. --plot representative draws the most persistent bar of --dimension (default 1), or --bar N (its line number in the listing, counting from 0); --at gives the scale. A comma list of kinds is one board, in a row or on --layout. Without --output the plot opens in the browser. See the command-line page.

Saved results

result.save(path) and --save-result write a JSON file that TDA4j.loadResult(path) and the command line read back, from MATLAB, Java or Scala: every bar, which bars the threshold reported, their representatives, the points or image, and how the result was computed (options, field, the version of tda4j). It is plain JSON, so other languages read it too: dimensions, births, deaths hold every bar, reported the indices of the reported ones, and representatives their cells and coefficients. Infinite and missing values are the strings "Infinity", "-Infinity" and "NaN":

import json
r = json.load(open("circle.json"))
deaths = [float(d) for d in r["deaths"]]    # float() reads numbers and "Infinity" alike

The boundary matrix is not saved, nor are the representatives of bars the threshold hid. With cocycles and every bar reported, a dimension-0 cocycle is a whole connected component, so such a file grows quickly with the number of points.

Plot.persistenceImage(d, degree), Plot.landscape(d, degree) the vectorizations of Vectorization

Plot.cycle(points, bar.representative) a simplicial cycle over its points (a chain, or its cells with coefficients as numbers)

Anything that takes a diagram also takes a list of bars. A cycle reads best over the complex it lives in:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = Array.tabulate(40)(i => Array(math.cos(i * 0.157), math.sin(i * 0.157)))
val d = Persistence(points, maxDimension = 1, engine = Persistence.Engine.Chunks)
import d.given
val loop = d.dim(1).longest.get
Plot.cycle(points, loop.representative).over(Plot.complex(points, loop.birth)).view()

A cocycle of a bar lives on the complex where the bar dies, so it has edges right across the data; restricted to the complex at the bar's birth (at = loop.birth) it shows the edges that cut the loop as it closes. A result's plotRepresentative(i) draws a cocycle that way, and plotRepresentative(i, Inf) draws it whole.

Customizing a plot

A plot is an immutable value, and each customization returns a new plot, so they chain:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val loops = Plot.diagram(d.dim(1))
  .withLabels(title = "The loops of a noisy circle", x = "birth", y = "death")
  .withXYScale(Transform.Log10)
  .withSize(640, 640)
loops.view()

The design follows the grammar of graphics: the plot constructors (Plot.barcode, Plot.diagram, ...) choose what is drawn, and the with... methods change the scales, the labels, the colors and the look, each independently of the others. Every argument is optional, and only what is given changes: withLabels(x = "birth (cm)") leaves the title as it is. Changes of different parts can come in any order; of the same part, the later one wins, keeping the rest of the earlier one (.withLabels(title = "A").withLabels(title = "B") titles the plot B).

to change method the same as a value
the words: title, subtitle, axis labels, legend heading, color bar title withLabels(title = ..., subtitle = ..., x = ..., y = ..., legend = ..., color = ...) Labels(...)
the size in pixels withSize(960, 540), or withSize(width = 900) to keep the height Size(...)
an axis: scale, limits, ticks, number format, gridlines withXScale(...), withYScale(...), withXYScale(...) Scale.x(...), Scale.y(...), Scale.xy(...)
the scale of a heatmap or a cocycle's values withColorScale(min = ..., max = ..., stops = ..., transform = ...) Scale.color(...)
the color, legend label and marker of a homological degree withDegree(1, color = "#c2185b", label = "loops", shape = Shape.Diamond) Scale.degree(...)
the color scheme withPalette(Palette.reference) the Palette itself
fonts, size of text and marks, gridlines, the legend's place, the background withStyle(Style.slides) the Style itself

the markers of points: shape, size, opacity, open or filled, the edge withPoints(shape = Shape.Star, size = 6, fill = false, edgeWidth = 0) Geom.points(...)
a barcode's bars, a complex's edges, triangles and balls withSegments(width = 3), withPolygons(opacity = 0.3), withDiscs(...), withLines(width = 3) Geom.segments(...), Geom.polygons(...), Geom.discs(...), Geom.lines(...)
each kind of text: size, weight, slant, alignment, font, color withText(TextRole.Title, size = 18, align = Anchor.Middle) Text(TextRole.Title, ...)

The right-hand column matters when a look is shared. Each change is also a tweak, a value: you can keep it in a val, combine tweaks with + and add the result to any plot, of any kind, with +. The look of a paper or a talk is then one val (see The look below). A tweak that means nothing for a plot (an axis of a 3-D scene) says so; one that merely has nothing to change (a color scale on a barcode) leaves the plot as it is, so one bundle fits every plot.

Labels, size and scales

An axis takes a scale (Transform.Log10, Transform.Sqrt, or Transform.SymLog(linear), logarithmic away from zero and linear within linear of it), the ends of the visible range, the tick positions and a printf pattern for the tick numbers, and can drop its gridlines or disappear altogether:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val barcode = Plot.barcode(d)
  .withXScale(max = 2, breaks = Seq(0, 0.5, 1, 2), format = "%.1f")
  .withYScale(grid = false)
barcode.save("barcode.svg")

min and max move one end each, so withXScale(max = 2) keeps the plot's own lower end.

Every value has a place on every scale. On a log axis what is at exactly 0, such as an H0 bar's birth, sits on a -∞ line just below the lowest number, labelled -∞ as an essential bar's end is labelled ∞; a bar born there starts from the line. A log axis with a negative value (a sublevel set of a function that goes below zero) is drawn as a symmetric log: logarithmic away from zero, linear within the smallest magnitude on the axis, zero in its place, and a line of small print under the plot says so. A square root keeps the sign, so a negative value is mirrored, and Transform.SymLog(linear) sets the linear stretch yourself. Only a value that is not a number at all is left out, and the small print counts it. withXScale(minusInfinity = false) leaves what is at 0 out of a log axis instead (counting it), and minusInfinity = true keeps the line with nothing on it, so that panels line up (Board.shared() does that for you). The diagonal of a diagram is drawn in the plot's own scales, so it is still the line y = x on a log-log diagram, and it starts where the numbers do, not at the -∞ line.

Colors

Homological degree k always has the same color and marker shape: degree 0 teal, degree 1 gold, degree 2 brick, so H1 looks the same in every plot whichever degrees are shown. The default palette is TDA4j's Teal & Gold, stepped for charts and checked for color-vision deficiencies (the first three degrees stay distinguishable side by side for every common deficiency). Palette.reference is a neutral alternative, and Palette.print is for a paper: black text on a background of exactly white, where the default's cream would print as a grey patch (Palette.grayscale is that without color, Palette.okabeIto is the eight colors of Okabe and Ito on the same white), and Palette.clear is black or white for a figure with no background (see For a paper). A palette recolors the whole plot, heatmaps and cocycles included, and you can make your own:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val onWhite = Palette.brand.withSurface("#ffffff") // a figure for a white page
val bold = Palette.brand.withSeries(Seq("#222222", "#c2185b", "#00796b"))

val diagram = Plot.diagram(d).withPalette(bold)
val image = Plot.persistenceImage(d, 1).withPalette(Palette.reference)
val paper = Plot.barcode(d).withPalette(onWhite)

One degree can be changed wherever it appears, in the marks, the legend and the dark mode alike, without touching the rest, and whichever palette the plot has:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val diagram = Plot.diagram(d)
  .withDegree(0, label = "components")
  .withDegree(1, color = "#c2185b", label = "loops", shape = Shape.Diamond)
  .withLabels(legend = "Homology")

Heatmaps (persistence images, images, cubical grids), cocycles and circular coordinates have a color scale, which maps the values to colors: heatmaps and cocycles through the palette's sequential and diverging ramps, circular coordinates through a cyclic one. withColorScale sets its limits, so that two plots are read on one scale, and the colors of a sequential ramp (ColorScale.viridis, ColorScale.greys, or any list of colors, light to dark) and how values are spread along it (Transform.Sqrt for a heavy-tailed image; the color bar then labels round numbers between its ends, each where the transform puts it). A cocycle's scale is symmetric about zero, so it takes only a max.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val image = Plot.persistenceImage(d, 1)
  .withColorScale(max = 0.05, stops = ColorScale.viridis, transform = Transform.Sqrt)
  .withLabels(color = "density")

The look

A Style holds what is not data: the font, a factor on the size of text and one on the size of markers and lines, the gridlines, where the legend goes (see The legend) and whether there is a background at all. Style.slides is a projector-sized preset (text and marks 30% larger); Style.print and Style.clear are for a paper and for a page of either color. A style replaces the plot's whole style; to change one setting of a style, copy it. Keep everything that makes a look a val, with +, and add it to every plot, of any kind:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val house = Style.slides.copy(legend = LegendPosition.Bottom) + Palette.reference + Size(960, 540)

Plot.barcode(d).withLabels(title = "Barcode") + house
Plot.diagram(d).withLabels(title = "Diagram") + house
Plot.points3D(points) + house

(Theme, which save and html take, is a different thing: whether the colors are light, dark, or follow the reader's own setting.)

Markers

A marker is a shape, drawn filled in its degree's color or open, with an edge around it: by default a ring of 2 pixels in the background's color, which keeps overlapping markers apart. Every part of that can be changed, for all the points of a plot or for one degree, and the edge can be taken away. The plots give each degree its own shape (circle, triangle, square, diamond), so that a diagram reads without color; there are more to choose from: Circle, Dot, Square, Triangle, TriangleDown, TriangleLeft, TriangleRight, Diamond, Pentagon, Hexagon, Star, the strokes Plus, Cross, VLine and HLine, and text, Shape.Glyph("★"), drawn in the marker's color.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val dense = Plot.diagram(d).withPoints(size = 3.5, opacity = 0.6, edgeVisible = false)
val open = Plot.diagram(d).withDegree(1, marker = MarkerStyle(fill = Some(false), size = Some(6)))
val stars = Plot.diagram(d).withPoints(shape = Shape.Glyph("★"), size = 7, edgeWidth = 0)

size is the radius in pixels, before the style's mark scale; opacity covers the marker and its edge; fill = false draws an open marker, an outline in its own color 1.5 pixels wide; the edge has a width (0 for none), a color or a palette role, an opacity and a dash, and edgeVisible = false takes it away. A plus, a cross and a bar are strokes: their edge is their color and their width is the edge's. A degree's markers (Scale.degree(k, marker = MarkerStyle(...))) win over the plot's marker settings, which win over the default. A 3-D scene's points are round and filled, and take a size, an opacity and an edge.

As text, a shape is a name (triangle-down, star, plus, ...), a one-letter code of matplotlib (o . ^ v < > s p h * + x D | _), a number of R and ggplot's pch (pch:16, or a bare 0 to 25: 0 to 14 are open shapes, 15 to 25 filled, the composite ones, 7 and 9 to 14, drawn as their outer shape) or glyph:text; any other single character is a glyph, and a code wins over a letter (glyph:x for the letter). marker.shape=pch:1 is an open circle: withSetting("marker.shape=pch:1"), withSetting("marker.edge-width=0"), withSetting("degree-1.size=6"), --set marker.shape=triangle-down.

The legend

The legend goes beside the plot (LegendPosition.Right, the default, or Left), above or below it (Top, Bottom, in rows that wrap), or inside the plot area at a corner (UpperLeft, UpperRight, LowerLeft, LowerRight), taking no room; or nowhere (Hidden). A persistence diagram puts it at the lower right by itself, below the diagonal where no point can be, in the shaded half plane. withLegend("right") or Style(legend = LegendPosition.Right) puts it beside the plot again; a style that does not name a place leaves each plot's own. A corner of a barcode over its bars covers some of them: choose the place for the plot, or give the legend a box.

A legend has no box unless you ask for one. withLegendBox(box = true) gives it the page's own color, a little see-through (opacity 0.9), and a thin frame, which keeps it readable over data wherever it is; background = "white" (or backgroundPaint) and opacity set the fill, frame = true, frameColor and frameWidth the line round it, and padding the room inside (6 pixels, growing with the legend's text size). A fill or a frame alone is a box of that kind, box = false takes it away. columns puts the entries in that many columns, a column filled before the next (seven entries in three columns are 3, 3 and 1); above or below the plot the columns line up as a grid beside the heading.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val d = Persistence(Array.tabulate(16)(i => Array(math.cos(2 * math.Pi * i / 16), math.sin(2 * math.Pi * i / 16))))
Plot.barcode(d).withLegend("upper-right").withLegendBox(box = true)
Plot.diagram(d).withLegend("bottom").withLegendBox(background = "white", columns = 3)

A legend takes at most two fifths of the figure's width beside the plot and at most the plot's width above, below or inside it: the columns that would take more are given up, so a legend never runs off the figure or over the plot.

The bars of a barcode

Plot.barcode(d, order = BarOrder.Persistence) sorts the bars of each degree longest first (Birth, the default, sorts by birth, Death by death); result.plotBarcode("persistence") is the same from MATLAB. withSegments(width = 3) sets their thickness in pixels.

Finer control: text, lines, the plot area, the sides of the axes

The style sets what applies to the whole plot. Each piece of text has a role, and each can be changed alone: Title, Subtitle, AxisLabel, TickLabel, Legend (the entries), LegendTitle, ColorTitle (the title of a color bar; its numbers are TickLabel), Note (the small print under a plot), Caption (the line under a plot, below) and Tag (the letter of a panel). A text has a size in pixels (before the style's text scale, so Style.slides still scales it), a weight, a slant, a font of its own, a color, and, for a title, subtitle, axis label and note, an alignment along the plot area. The tick labels of the x axis can be slanted by an angle. The margins follow the text: a larger tick label makes room for itself.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val figure = Plot.diagram(d)
  .withLabels(title = "Loops", subtitle = "a noisy circle", x = "birth", y = "death")
  .withText(TextRole.Title, size = 20, align = Anchor.Middle)
  .withText(TextRole.Subtitle, italic = true, align = Anchor.Middle)
  .withText(TextRole.AxisLabel, weight = Weight.Bold)
  .withText(TextRole.TickLabel, size = 9)
  .withGridLines(dash = Dash.Dotted)
  .withTickMarks(length = 4)
  .withMinorTickMarks(length = 2)
  .withFrame()
  .withPanel(color = "#f4f4f4", opacity = 1.0)
  .withDiagonal(shade = false, dashed = true)
  .withXScale(position = Side.Top)

The lines are the gridlines, the axis lines, the tick marks and a frame around the plot area, each with a width, a color or a palette role (so that it follows the theme), a dash (Dash.Solid, Dashed, Dotted) and an opacity. Minor tick marks, minor gridlines and the frame are not drawn unless asked for, and giving any of them a setting asks. On a log axis the minor ticks are the whole numbers of each decade that are not ticks; on any other axis, the halves between two ticks. Tick marks point out of the plot (TickDirection.Out) or into it, and the numbers move out of their way. A tick mark asked for with no length is 4 pixels long.

Guide.panel fills the plot area, behind the gridlines. Guide.diagonal restyles the diagonal of a persistence diagram and its shaded half plane (shade = false for none, shadeColor, shadeOpacity); a figure without a diagonal is left as it is. Scale.x(position = Side.Top) puts the x axis above the plot, with its numbers, label and tick marks, and Scale.y(position = Side.Right) the y axis at the right, the legend moving out past it.

Each of these is also a value you can keep in a val and add to any plot; changes of the same element keep what the earlier ones set, and tweaks of different elements come in any order, a Style included, which never undoes them.

As text. MATLAB, Java and the command line (--set) write the same changes as element.property=value:

fig.withSetting("title.size=18"), fig.withSetting("grid.dash=dotted") and java -jar tda4j-assembly.jar --plot diagram --set title.size=18 --set ticks.length=4 ... are the same changes. A name that is not one, a number that is not a number and a setting a plot cannot have (a tick label of a 3-D scene, which has a title, a subtitle and a hint) are errors that say what to write instead.

The axes: direction, room, shape and scales of your own

Scale.x(reverse = true) runs an axis backwards, the way a depth or a rank is drawn: the larger numbers are at the left (or at the bottom). Everything drawn in the plot follows, the half plane below the diagonal of a persistence diagram included, and the boxes of a heatmap stay boxes. padding is the room left around the data, as a fraction of their extent (a plot has 0.04 of it on each side; 0 puts the first point on the axis). withAspect(2) makes a y unit twice as long as an x unit on the page, withAspect(1) makes them equal (a persistence diagram begins so), and withAspect(free = true) lets the units differ.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

// the bars from the largest scale down, with no room beyond the data on the x axis
val backwards = Plot.barcode(d).withXScale(reverse = true, padding = 0)

// a scale of your own: the cube root, which spaces 1, 8 and 27 evenly
val cubeRoot = Transform.Custom("cube root", math.cbrt, v => v * v * v)
val cubic = Plot.barcode(d).withXScale(cubeRoot)

// the units of a diagram freed from each other
val loose = Plot.diagram(d).withAspect(free = true)

A scale of your own gives a name (the one messages use), the map to the line and the map back, which must undo each other; the ticks are round numbers of the data, as on a square-root axis. Keep the functions in a val: two axes are on one scale (for Board.shared()) when they hold the same functions.

An axis through a value. An axis is drawn at the bottom (or the top) of the plot and at its left (or right). For data that go negative, crossesAt draws it through a value of the other axis instead: Scale.x(crossesAt = 0) is the x axis through y = 0, Scale.y(crossesAt = 0) the y axis through x = 0, each value in the units of the axis it crosses (a log axis takes the data's own number, not its logarithm). The numbers stay beside the line, below it or to the left of it, or above it and to the right when the axis is given the other position; the tick marks start on it and the gridlines still run across the plot. The axis label stays at the edge, where the data are not, and the margin the numbers needed is given back to the plot. reverse is followed, so is any scale.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.plot.*

// a ring of points drawn round the origin, as a mathematician draws it
val points = Array.tabulate(40)(i => Array(math.cos(i * 0.157), math.sin(i * 0.157)))
val ring = Plot.points(points).withXScale(crossesAt = 0).withYScale(crossesAt = 0)

A value the other axis does not show (a plot of positive numbers asked to cross at 0) or cannot place (0 on a log axis) leaves the axis at the edge, and a line of small print under the plot says so, so one house style with crossesAt fits every plot. x-axis.crosses-at=0 and y-axis.crosses-at=0 are the same as settings, withXCrossesAt(0) and withYCrossesAt(0) from MATLAB.

Numbers

Numbers sets how the numbers of the tick labels and the color bar are written: the decimal separator, a mark between groups of three digits, and the minus sign. Numbers.locale("de") takes what a locale writes (a comma and a hyphen for German, a comma and a true minus sign − for Swedish; the digits stay 0 to 9, so Arabic has a point, not its own decimal separator); the symbols can also be given one by one. Anything that is not a number, such as an H0 in a legend, is left alone.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val german = Plot.diagram(d).withLocale("de")
val typographic = Plot.diagram(d).withNumbers(decimal = ",", minus = "−", grouping = " ")

A long text can be cut: Text(TextRole.Legend, limit = 120) ends a legend entry that would be longer than 120 pixels in an ellipsis, and the whole text is the tooltip of what is left. The renderer has no font metrics, so it estimates the length of a text letter by letter from the advance widths of Helvetica (for sans-serif, system-ui, Arial and the like), Times (serif) or a fixed width (monospace); a font with other proportions is cut some characters from where the estimate puts it. The legend makes room for the same estimate of its widest entry (TextWidth.of(text, size)).

A caption, a panel tag and a description

Labels(caption = ...) puts a line under the plot, at the left of the plot area, and takes its room; tag puts a short label in the corner of the figure, in a larger, semibold face, the way a journal letters its panels; description is what a screen reader says of the plot (the <desc> of the SVG). A barcode and a diagram describe themselves, with their counts by degree, unless you give another. Board.tagged() letters the panels of a board (a), (b), ...; tagged("%s.", "A") writes A., B., and the sequence "1" counts.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val one = Plot.diagram(d)
  .withCaption("Source: a noisy circle")
  .withDescription("One long-lived loop, far from the diagonal")
val board = Plot.side(Plot.diagram(d), Plot.barcode(d)).tagged()

A 3-D scene has none of the three; asking says so.

Sizes in the units of a paper

A figure's size is in pixels, 96 to the inch. Size.inches(3.4, 2.6), Size.cm, Size.mm and Size.pt are the sizes in the units of a journal's template (Size.pt(245) is a column), and size.width=3.4in says the same as a setting. Add the size with + as any tweak: Plot.diagram(d) + Size.inches(3.4, 2.6). The text keeps its size in pixels, so check it against the column.

The camera of a 3-D scene

A 3-D scene is drawn from one view in a saved .svg, and on a page it starts from that view and can be turned (drag) and zoomed (scroll). Camera(azimuth, elevation, zoom) sets it: the azimuth turns the scene around the vertical axis and the elevation raises the eye above the horizon, both in degrees (from the front, azimuth = 0, elevation = 0; the default view is -35 and 25), and the zoom is how close, from 0.2 to 8 (2 shows the scene twice as large, round the middle of the plot). Only what is given changes. A 2-D figure has no camera and says so.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val helix = Array.tabulate(60)(i => Array(math.cos(0.3 * i), math.sin(0.3 * i), i / 30.0))
val scene = Plot.points3D(helix).withCamera(azimuth = 20, elevation = 10, zoom = 1.3)
scene.save("helix.svg")

From MATLAB it is scene.withCamera(20, 10, 1.3) and scene.withSetting('camera.zoom=1.3'); on the command line, --plot input-3d --set camera.azimuth=20 --set camera.zoom=1.3.

For a paper, and for a page of either color

Two looks are ready-made, each a palette and a style, and they differ in what is behind the figure.

Palette.print and Style.print are for a figure that has a white background of its own, as in a paper, in a saved file too. The palette is black text and axes on a surface of exactly white (the default's cream would print as a grey patch); its degree colors stay apart for every common color vision and read on white (blue, vermillion and bluish green for degrees 0 to 2, checked on all pairs), and its heatmap ramp darkens steadily, so it keeps its order on a grayscale printer. It has one look: the dark theme draws the same figure. The style names fonts that converters and publishers know (Helvetica, Arial) instead of the browser's own system-ui.

Palette.grayscale is print with no color at all, for a paper that prints in black and white. Degrees are told apart by lightness (a dark, a light and a middle gray first, each dark enough to show on white) and by the marker shapes and the legend, which every palette keeps: past four degrees the grays run out, so rely on the shapes. A heatmap uses ColorBrewer's Greys, darker for larger. A diverging scale (a cocycle's values) is a dark gray against a middle gray around a light middle, a weaker cue for the sign than a hue; use Palette.print for those when color is available.

Palette.okabeIto is the color-blind-safe palette of Okabe and Ito on print's white surface and black ink, with the same heatmap ramp and the same blue against vermillion for a diverging scale. Degrees 0 to 2 are its blue, vermillion and bluish green, which stay apart side by side for every common color vision; the next colors are orange, sky blue and reddish purple, then yellow and black. Orange and sky blue are lighter than a thin mark wants against white, and yellow barely shows on it, so they come last: past the third degree, rely on the marker shapes and the legend. Like print it has one look for both themes, as Okabe and Ito defined their colors for a light background. The palette is validated as accessible on white only; on any other background the checks no longer hold.

Palette.clear and Style.clear are for a figure with no background, that takes the color of what is behind it. The style draws none, on a page as in a file (a saved .svg has none anyway, unless its style asks for one). The palette has two looks, which the theme picks: pure black elements for a light page (Theme.Light, what an .svg file gets) and pure white ones for a dark page (Theme.Dark), each with degree colors chosen to read on its own page color. Theme.Auto follows the reader's setting, which is right only where the page does too. Without the style, a figure shown on a page keeps the white or the black background of its mode.

A size is in pixels of 1/96 inch, and text is 11 to 15 pixels. Give the figure the size it has on the page and place it at that size, and its text comes out at the size the journal asks for: a 3.4-inch column is 326 pixels, in which tick labels are 8.25 pt. For a serif face to match the text of the paper, copy the style:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val paper = Palette.print + Style.print + Size(326, 260)
val serif = Palette.print + Style.print.copy(font = "'Times New Roman', Times, serif") + Size(326, 260)
val overlay = Palette.clear + Style.clear

Plot.diagram(d).withLabels(x = "birth", y = "death") + paper
Plot.barcode(d) + serif
(Plot.diagram(d) + overlay).save("for-a-light-page.svg")
(Plot.diagram(d) + overlay).save("for-a-dark-page.svg", Some(Theme.Dark))

Defaults for every plot: a given Look

When all your plots should be in one house style, say so once. A Look is a list of the same tweaks a plot takes, and every plot constructor (Plot.barcode, Plot.diagram, Plot.landscape, the 3-D ones, ...) starts from the given Look it finds. Nothing is imported: a given in your file, or in the block where you draw, is found. Without one, a plot is as its constructor makes it.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val d = Persistence(CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv"), maxDimension = 1)

given Look = Look.print + Text(TextRole.Title, size = 18) + Lines.grid(dash = Dash.Dotted)

Plot.barcode(d).save("barcode.svg") // in the look
Plot.diagram(d, palette = Palette.reference).save("diagram.svg") // a palette named in the call wins
(Plot.barcode(d) + Style.slides).save("slides.svg") // and so does a tweak added afterwards

Look.print and Look.clear are the palette and style of the two looks for a paper (see above), Look.none is nothing, and Look.named("print") takes a word. Add tweaks with + and looks with ++; the later one wins. A look serves figures and 3-D scenes alike: a tweak that a kind of plot cannot have (the tick labels of a scene) is left out for it, so the same look works for Plot.barcode and Plot.points3D. A given in a smaller scope replaces one in a larger, whole. To add to the look in scope instead, ask for it: given Look = summon[Look] + Text(TextRole.Title, size = 21) in an inner scope (a block, a method, a file that imports a shared look) is the look of the enclosing scope with one more tweak, or, where you have given none, the default (which changes nothing) with it. In the same scope as the look it builds on, it is an ambiguity error, as are two given Looks in one scope: nothing is merged silently. The default is found only when you have given no look.

From MATLAB and Java, which have no givens, a session has defaults of its own: TDA4j.setPlotDefaults takes the same settings as text (palette=print, style=print, title.size=18, ...), and every plot a result draws afterwards starts from them until TDA4j.clearPlotDefaults(). They belong to the thread that set them, which for MATLAB is the whole session.

import org.appliedtopology.tda4j.matlab.*;

TDA4j.setPlotDefaults({'palette=print', 'style=print', 'title.size=18'});
result = TDA4j.computeFromPoints(points, {'maxDimension', '1'});
result.plotBarcode().save('barcode.svg');      % in the print look
result.plotDiagram().withStyle('slides')       % what you chain on wins
TDA4j.clearPlotDefaults();

Comparing plots

Plots drawn side by side mean something only on the same scale. shared() gives every panel of a board the union of the panels' ranges, on both axes or on shared(y = false) the x axis only; a tweak added to a board with + changes every panel (Labels(title = ...) titles the board: the heading above the panels, and the title of the page it is saved as):

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val a = Persistence(CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv"), maxDimension = 1)
val b = Persistence(CSV.readPointCloud("_docs/tutorials/data/noisy-circle-b.csv"), maxDimension = 1)

val board = Plot.side(Plot.barcode(a).copy(title = "first"), Plot.barcode(b).copy(title = "second")).shared(y = false)
(board + Style(grid = false)).save("compare.svg")

Panels on a grid

Plot.side puts panels in a row. For more, Plot.layout(rows, cols) is an empty board on a grid of cells, and place(figure, row, col, rowSpan, colSpan) puts a panel with its top left corner in a cell and spanning as many rows and columns as it is given: a panel is as large as the cells it spans and the gaps between them, so its axes run across all of them. Cells count from 0. The drawing is width by height pixels (960 by 600), gap pixels between cells; the columns share the width equally unless widths gives their relative sizes (Seq(1.0, 3.0): the second column is three times as wide as the first), and so the rows with heights. The grid sets the size of every panel.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val d = Persistence(CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv"), maxDimension = 1)

val board = Plot.layout(2, 3, widths = Seq(2.0, 2.0, 1.0))
  .place(Plot.diagram(d), row = 0, col = 0, colSpan = 2, fill = true)
  .place(Plot.barcode(d), row = 0, col = 2)
  .place(Plot.barcode(d).withXScale(Transform.Sqrt), row = 1, col = 0, colSpan = 3)
  .tagged()
board.save("grid.svg")

A persistence diagram keeps equal units, so in a wide cell the data take a square and the rest is empty axis; fill = true (the same as withAspect(free = true) on that panel) lets it fill the cell, as above. A panel that would cover a cell another one covers, or that runs off the grid, is refused when it is placed, naming the panel in the way. tagged() letters the panels in the order they were placed.

On a grid, sharedColumns() puts the panels over the same columns on one x scale and sharedRows() the panels across the same rows on one y scale, each column and row its own (shared() still takes all panels together). A panel that spans columns is a kind of its own: it shares with no panel over one column. A panel alone in its group keeps its own axes as they are. The same two methods on a row of panels share nothing along columns (each is in its own) and everything along the row.

Reference lines and marks of your own

Mark.Rule draws a line across the plot at one value, and Mark.Diagonal(offset) the line y = x + offset: a threshold on a barcode, or the line above which a point of a diagram persists longer than offset. They take no part in choosing the visible range. Any other Mark can be added with + as well, in data coordinates:

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*
import org.appliedtopology.tda4j.plot.*

val points = CSV.readPointCloud("_docs/tutorials/data/noisy-circle.csv")
val d = Persistence(points, maxDimension = 1)

val diagram = Plot.diagram(d) +
  Mark.Diagonal(offset = 0.2, paint = Paint.Muted, dashed = true) +
  Mark.Text((0.1, 1.2), "persistence 0.2", anchor = Anchor.Start)
val barcode = Plot.barcode(d) + Mark.Rule.vertical(0.5)

From MATLAB and the command line

MATLAB and Java have no named or default arguments and cannot build a Palette or a Transform. A plot... method of a result returns a figure (a plot...3D method a scene), and a scene has the subset marked below.

import scala.language.experimental.modularity
import org.appliedtopology.tda4j.*

val d = Persistence(points, maxDimension = 1)

val diagram = Plot.diagram(d).withLabels(title = "A noisy circle", x = "birth", y = "death").withSize(800, 600)
diagram.save("diagram.svg")
Plot.barcode(d).withXScale(Transform.Sqrt).withStyle(Style(textScale = 1.3)).save("barcode.svg")

import numpy as np
import tda4j

points = np.loadtxt("_docs/tutorials/data/noisy-circle.csv", delimiter=",")
result = tda4j.persistence(points, max_dimension=1)

result.plot_diagram().with_title("A noisy circle").with_x_label("birth").with_y_label("death").with_size(800, 600).save("diagram.svg")
result.plot_barcode().with_x_scale("sqrt").with_text_scale(1.3).save("barcode.svg")

The command line has a flag for the same changes of a --plot: --title, --x-label, --y-label, --caption, --tag, --description, --layout and --tagged (for a list of kinds on a board), --look (default, print or clear: the palette and style together, which the flags after it override), --width, --height, --palette (brand, reference, print, grayscale, okabe-ito or clear), --style (default, slides, print or clear), --theme (light, dark or auto), --text-scale (applied to the --style), --set (repeated, element.property=value), --x-scale and --y-scale (linear, log, sqrt or symlog). A word that is not one, a size out of range and a flag a plot cannot use (an x scale for a 3-D scene) are errors, reported before anything is computed:

java -jar tda4j-assembly.jar --plot diagram --title "A noisy circle" --x-scale sqrt --width 800 --output diagram.svg circle.json

Every plot is an immutable value, and Figure, Mark and Scene are there to build plots of your own: copy(...) changes any part directly, Tweak(f) makes a tweak of your own from a function on figures, and over draws one figure on another.
